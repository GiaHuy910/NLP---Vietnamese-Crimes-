# Vietnamese Crimes NLP

The NER implementation and run instructions are in [server/README.md](server/README.md).

The local `server/datasets/train.csv`, `valid.csv`, and `test.csv` currently contain
the supplied annotations plus 100 synthetic examples appended to each split for a
pipeline smoke test. The synthetic examples are not real news or human-verified
annotations, so results on the current test split are not a real-world benchmark.
Dataset and model artifacts are local and are not committed.
